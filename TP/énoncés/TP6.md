# Objectifs

Découvrir un peu le principe des SPA avec une application Angular.
Brancher un front-end et un back-end ensemble pour voir un peu les interactions entre les deux.

# Sujet
## Première prise en main d'Angular

Rendez-vous sur https://angular.dev/tutorials/first-app et réalisez les commandes demandées dans la barre de gauche (normalement, il ne vous reste que la 3 à faire).

Réalisez les exercices proposés sur https://angular.dev/tutorials/learn-angular/1-components-in-angular pour prendre un peu en main le framework, arrêtez-vous après l'exercice Event handling.

N'hésitez pas à demander si vous avez des questions.

## Un projet en place

Une fois les premiers exercices réalisés et ng installé sur votre machine (ng -v pour vérifier), mettez vous dans le projet pokemon-front-end et lancez-le, soit avec IntelliJ, soit avec la commande npm start.
